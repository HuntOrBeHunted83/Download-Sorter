Download Manger

How to Use

This download manager organizes your downloads by file type (such as png, jpeg, or zip) or by the website they come from.

To create a rule, enter a website name or file extension. Then, select the matching option using the buttons.

Rules with higher priority are applied before other rules.

Use the checkbox next to a rule to enable or disable it.

When you download a file, the folder set by the matching rule will be selected automatically on the downloads page.

The folder should be in the format of "FOLDERNAME"/. Example: (JPEG/)
